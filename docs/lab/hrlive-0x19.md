# 心跳直播的协议笔记：service `0x19`（HrRriTest）

> 这页是给「想自己接这条路」的人看的：手环推什么、我们发什么、哪些是**已验证**、哪些是**还没真机量过**的。
> 代码在 `bandcore/.../data/HrLiveSession.java`（会话）和 `bandcore/.../proto/hr/RriBeats.java`（换算）。

## 一句话

华为手环除了「每分钟一格」的心率记录，还有一路**逐拍（RRI）**数据：
开一次测量，手环把**每一拍**的心跳间隔推上来，`心率 = 60000 / 间隔(ms)`。

Gadgetbridge 里这个类叫 `HrRriTest`，它只被用在**压力校准**（`HuaweiStressCalibration`）：
开 60 秒、收 RRI 算 HRV、出压力分、关掉 —— 从来不算心率。所以以前「没实时心率」的结论是对的，
但「没有别的数据可拿」是错的。

## 报文

| 方向 | service / command | TLV | 说明 |
|---|---|---|---|
| 手机 → 手环 | `0x19 / 0x01` | `{0x01: 0x03}` | 开始测量（**加密包**，不能拿 BLE 调试工具手拼 hex） |
| 手环 → 手机 | `0x19 / 0x01` | `{0x7f: 0x000186A0}` | 应答；`0x7f` 是返回码，`0x186A0` = 成功 |
| 手环 → 手机（推送） | `0x19 / 0x05` | `0x82` 容器 → 若干 `0x83` 子容器 | 每个子容器：`0x04` = `rri`（short，毫秒），`0x05` = `sqi`（byte，信号质量，`0` = 这拍不可信） |
| 手机 → 手环 | `0x19 / 0x01` | `{0x01: 0x04}` | 结束测量 |

- `type` 目前只用过 `3`（开）/ `4`（关）—— 这是 Gadgetbridge 的用法，真机上两个都被接受。
  **其它取值（1/2）和 `0x19/0x04` 的语义未验证**，别瞎试。
- `sqi == 0` 的拍要丢掉：Gadgetbridge、以及本项目的压力校准都是这么筛的。
- `rri` 按无符号读（`& 0xFFFF`）；`sqi` 也按无符号读（`& 0xFF`）。
- 合理范围：`250 ms`（240 bpm）～ `3000 ms`（20 bpm），超出就是漏拍/断拍。

## 已验证的（真机）

- 设备：HUAWEI Band 10（`Nora-B19FP`）。2026-11-22 21:02:02 开流 → 21:03:02 关流：
  - 开、关两次 `0x19/0x01` 都回了成功码 `7f04 0001 86a0`；
  - **60.9 秒收到 85 拍**（`n=85`，间期样本 `534, 894, 626, 564, 969, 477, 554, 565 …` ms，
    平均 ≈706 ms ≈ 85 bpm）；
  - 这批数据当时被拿去算压力分了，但**数据本身确实是逐拍心率**。
- 所以「手环愿意把逐拍数据吐给第三方 App」这件事，已经证实。

## 还没验证的（0.1.1 想量的就是这些）

1. **推送延迟**：每个 `0x19/0x05` 包装几拍、多久来一包。`lag = 包到达时刻 − 按 RRI 累加出来的最后一拍`
   - `lag` 几百毫秒～几秒 → 这条是真「近实时」，可以做「心跳在跳」的界面；
   - `lag ≈ 60 秒` → 手环是攒一批才推，那就只能做「测一分钟 → 回放这一分钟」。
2. **能不能开超过 60 秒**：Gadgetbridge 只开到 60 秒（因为压力校准只要 60 秒），更久没人试过。
   本项目给了 60 秒和 3 分钟两档，3 分钟那条在界面上标了「未验证」。
3. **测量期间手环屏幕 / 耗电**：没有量过。
4. **运动/走路时 SQI 掉多少**：静坐肯定能测，动着能不能用没量过。

## 怎么复现

App 里：连上手环 → 「心跳直播」卡片 → 「开始（1 分钟）」→ 静坐 30 秒 → 看卡片和日志页
（探针前缀 `hwlive`：`open-ack` / `first-pkt` / `pkt … lag=` / `end`）。

MCP：`band_hr_live`（`seconds` 传了就开一次；不传只读当前）。

当库用（bandcore 自包含，不需要 Android）：

```java
HrLiveSession live = new HrLiveSession(requestRunner);     // 已经认证好的传输
live.start(60, (bpm, bpmAvg, beats, lagMs, lastBeatMsAgo) -> { /* 你的 UI / 前端事件 */ });
// 或者已经有 worker 线程：live.runBlocking(60, callback)
HrLiveSession.Snapshot snap = live.snapshot();
```

只想把 RRI 换算成心率，不碰蓝牙：`io.github.bandbridge.core.proto.hr.RriBeats`。
